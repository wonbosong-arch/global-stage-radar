# 중국 본토 업종 대시보드 연구 스냅샷

`data-validation-mvp` 1b086c5 기반, 연구 브랜치 17c409960d54441346e575f4eee04e09c5c63d59에서 6개 파일만 선택 복사했다. 연구 코드·수집 설정·운영 가격·유니버스는 가져오지 않았다. `manifest.json`에 원본 경로와 원본 바이트 SHA256을 보존한다.

가격 8,905행, 30종, 2025-07-30~2026-10-27. 출처는 기존 KIS 해외 일봉 후보 관측(SHS)이며 수집 경로는 `refresh_china_candidate_prices.py` → `KISUSProvider.fetch_daily` → 클라이언트의 `daily_bars` (`kis_provider.py`)다. API 요청의 MODP=1은 공식 가격 차이 해소나 조정주가 품질 검증을 의미하지 않는다. 현재 통합 기준의 더 최근 후보 가격 파일과 섞지 않는다.

등록부의 `data_rights`, `adjusted_price_quality`, 한국 브로커 주문 가능성, 최신 방법론 버전/시행일은 미검증이다. 운영·재배포 이용권 승인 문서는 발견되지 않았다. 이 사본은 격리된 연구 미리보기 근거이며 운영 사용 승인이 아니다. 실거래 가능성이나 유동성 우월성을 주장하지 않는다. 본 스냅샷 및 화면 공개·상업적 재사용 전에는 별도 이용권 확인이 필요하다.

공식 거래소 대사는 2026-07-28~2026-10-27의 60개 관측일에 한정된다. `official_market_reconciliation.csv`에는 공식/기준 OHLC·좌수·거래대금·보존 원문 해시가 있고, `official_liquidity_60d.csv`에는 출처 URL이 있다. 공식 원문과 세부 분석은 연구 브랜치의 `research/china_etf_review_20261102/followup/`에 남겨 둔다. 첨부 한국어 보고서의 상대 링크는 원 연구 브랜치 기준이다.

대시보드는 전체 파일 해시, 공식 신원, 종목별 60일의 유일성·OHLC/거래량 일치, 가격 구조 및 실제 표시 데이터와 기준값의 동일성을 확인한다. 11종의 이 60일만 차트에 전달한다. 512400은 31일 OHLC 차이로 전체 차트가 차단된다. 비교후보 512700은 25일 차이가 있으며 대표 12종에 포함되지 않는다. 마지막 불완전 주봉은 제외하고 150봉 기본 창에서 존재하는 짧은 이력만 표시한다. 30주 이동평균 산출에 부족한 주봉 이력을 과거 미검증 구간으로 채우지 않는다.

12종 모두 Stage 계산·신규 Stage2 표시·운영 승격을 수행하지 않는다. 활성 screen/prices/weekly_by_symbol 및 관심 목록 카탈로그에 추가하지 않는다. KWEB/CQQQ는 기존 미국 상장 프록시 경로를 유지한다. 기존 업종 화면의 연구 보고서는 종전대로 유지되며 신규 중국 탐색은 별도 자료 선택으로 들어간다.

검증: `tests/test_china_dashboard.py`, `browser_checks/check_china_dashboard.py`. 실제 브라우저 검사는 기존 offline harness를 사용하고 공급자 요청을 차단한다. Windows에서는 `PYTHONUTF8=1`을 설정한다. 기존 워크플로는 수정·수동 실행하지 않는다.
