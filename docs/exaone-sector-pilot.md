# K-EXAONE 2.5 미국 종목 업종 분류 파일럿

저장소 루트에서 기본 모드로 실행하면 고정된 미국 상장 종목 20개의 모의 응답을
재생해 UTF-8 JSON을 표준 출력에 씁니다. 샘플 설명은 이 검증을 위해 작성한
짧은 공개 사업 설명입니다. 기존 업종 제안의 12개 라벨(반도체 별도)을
포함하도록 샘플을 선정했습니다.

```powershell
python -X utf8 exaone_sector_pilot.py
python -X utf8 -m unittest discover -s tests -p test_exaone_sector_pilot.py
```

모의 입력과 기대 검토 결과는 `tests/fixtures/exaone_sector_samples.json`과
`tests/test_exaone_sector_pilot.py`에 있습니다. 20건 중 유효 응답은 19건이고,
기존 `stock_mapping.proposed_stock_mapping`의 업종 제안과 18건이 일치하고 1건이
불일치합니다. 스키마 오류 1건, 낮은 신뢰도 1건, 입력에서 찾을 수 없는 근거 1건을
재현합니다. 신뢰도·근거 사례는 일치 18건 안에 포함됩니다. 비교 기준은 검토용
제안이며, 이 재생 결과는 실제 모델 정확도 또는 검증된 업종 건수를 측정하지 않습니다.

## 보고서와 검토

- `sector`와 `industry`는 각각 저장소 분류 체계의 제안과 모델의 한국어 세부 업종명입니다.
- `evidence`에는 샘플 설명에서 실제로 찾은 인용구만 기록합니다. 인용구는 원천 자료의 사실성이나 결론의 적합성을 보증하지 않습니다.
- `model_confidence`는 모델이 보고한 0~1 값입니다. 0.75 미만을 파일럿의 낮은 신뢰도로 구분합니다.
- `review_status`는 전 행 `pending_review`입니다. `review_reasons`는 낮은 신뢰도, 근거 부족, 미분류, 기존 제안과의 불일치 등을 구분합니다. `error`에는 고정 오류 코드가 들어갑니다.
- 보고서는 표준 출력 전용입니다. 후보·활성 목록, 기존 업종·벤치마크 매핑, 대시보드, Stage 계산에 연결하는 경로는 없습니다.

## 수동 실측

실측은 사용자가 이용 조건을 확인하고 로컬 프로세스의 `EXAONE_API_KEY` 환경변수를
설정한 상태에서 아래처럼 명시적으로 실행할 때만 시작합니다. 모의 모드와 CI에는 키가
필요하지 않습니다.

```powershell
python -X utf8 exaone_sector_pilot.py --live
```

키는 환경변수에서 읽어 고정 HTTPS 호스트의 인증 헤더에만 보냅니다. 전송하는 샘플
내용은 티커, 거래소, 발행사명, 짧은 사업 설명입니다. 기존 분류와 모의 정답은
전송 대상에서 제외합니다. 요청 바이트를 UTF-8로 인코딩하고 응답 바이트를 UTF-8로
엄격히 디코딩합니다. `choices[0].message.content`만 분류 JSON으로 검증하며
추론 텍스트, 응답 원문, 오류 본문은 보고서에서 제외합니다.

- 한 번에 한 종목을 처리하고 요청 사이에 최소 1초 대기합니다. 요청의 소켓 제한은 90초이며 응답 본문 한도는 128 KiB입니다.
- 429, 일시적 서버 오류(500/502/503/504), 전송 오류에는 첫 시도 포함 최대 3회까지 요청합니다. 기본 대기는 1초, 2초입니다. 서버가 제공하는 `retry-after`와 `retry-after-ms` 중 더 긴 대기를 적용하며, 10초를 초과하면 배치를 중단합니다.
- 인증 오류, 리디렉션, 재시도 소진 시 남은 행은 `not_attempted_after_stop`으로 기록합니다. 400/422나 응답 검증 오류는 해당 행에서 끝나며 다음 샘플로 이동합니다. 실측에서 오류가 발생하면 보고서를 출력하고 종료 상태 1을 반환합니다. 키가 없거나 형식이 잘못되면 호출 전에 종료 상태 2를 반환합니다.
- 재시도된 요청도 제공자의 사용량에 포함될 수 있습니다. 이 변경에서 실측 호출은 0건입니다. 실제 응답·분류 품질·계정의 호출 한도는 수동 실측 항목입니다.
