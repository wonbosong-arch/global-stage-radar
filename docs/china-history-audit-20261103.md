## 기존 자료와 검증 공백

- KIS 연구 커밋 `17c4099`의 `data/china_candidate_prices.csv`: 8,905행/30종.
  이번 입력 SHA256은 `327c70efa1c1b0983b8cd157dd574c9acb22fdc351ef4faff6f191475c7a7d0c`.
  대표 12종은 각각 299~300거래일, 2025-07-30 또는 07-31~2026-10-27,
  구조상 완료 주봉 63개다. 길이만으로 검증된 조정 이력이 되지 않는다.
- 기존 `refresh_china_candidate_prices.py`는 3페이지를 수집하고 기존 이력을 합친다.
  `kis_provider.py`는 일봉 요청에 `MODP=1`을 사용한다. 중복일은 후속 수집값으로
  덮어쓰므로 조정 버전/기업행사에 대한 독립 감사 근거가 되지 않는다.
- 연구 `research/china_etf_review_20261102/followup/market_manifest.json`의
  SSE 응답은 110일이다. 요청은 `https://yunhq.sse.com.cn:32042/v1/sh1/dayk/{symbol}`,
  `begin=-110&end=-1&period=day&select=date,open,high,low,close,volume,amount`.
  기존 `analyze_followup.py`는 KIS 마지막 60일만 대사했다.
- 이번에는 기존 저장 응답만 사용했다. 추가 KIS/SSE 수집은 없었다. SSE 원문과
  기존 수집 영수증의 해시/종목/HTTP 상태/필드 순서/출처 경로를 대조하고 XSHG
  거래일·OHLCV·거래대금/거래량 일관성을 검사했다. 해시는 로컬 바이트의 동일성만
  확인하며 출처의 진위나 조정 기준을 증명하지 않는다.

## 재현

공개 Git checkout 밖의 `CHINA_PRIVATE_SNAPSHOT_DIR` 아래에 기존 입력을 개인적으로 둔다:
`china_candidate_prices.csv`, `market_manifest.json`, `sources/{symbol}_sse_daily.json`.
도구는 Git checkout 내부 입력과 심볼릭 링크를 통한 내부 경로를 거부한다.

```powershell
$env:CHINA_PRIVATE_SNAPSHOT_DIR = 'C:\private\china-history'
$env:PYTHONUTF8 = '1'
python china_history_audit.py --as-of-date 2026-11-03
python -m pytest -q tests/test_china_history_audit.py tests/test_china_readiness_validation.py tests/test_china_stage_guard.py
```

출력은 종목별 개수·구간·진단·입력 해시뿐이다. 원문 가격/거래량/지표/Stage 또는
활성화 권한을 생성하지 않으며 기존 차트 로더와 연결하지 않는다. 외부 입력 선택은
검증된 이용권이나 출처 진위를 의미하지 않는다. 원문과 로컬 상세 결과는 커밋하지 않는다.
