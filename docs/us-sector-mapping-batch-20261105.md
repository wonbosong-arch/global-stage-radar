# 미국 업종 근거 일괄 매핑과 확대 한계 — 2026-11-05

저장된 근거만 사용하는 이번 실행에서는 분석 가능 종목이 **85 → 85개**다.
신규 통과 0개이며 업종을 추정하여 수를 늘리지 않았다. 일괄 생성·충돌 분류·
데이터 검사·기존 엔진 연결은 구현했고, 합성 편입 자료의 복수 신규 종목으로
실제 계산 경로를 회귀 검증했다. 실제 확대가 막힌 원인은 가격 수집보다
저장된 업종 근거의 범위다.

## 구현과 보류 규칙

`us_sector_mapping_batch.py`는 여러 저장 편입 행을 정확한 symbol/venue/name으로
일괄 연결한다. 근거 파일은 `--sources`로 지정할 수 있다. 기본은 기존 14개
주석이며 새로운 종목 목록을 하드코딩하지 않았다. 기존 `stock_mapping.py`의
제안과 시장/ADR 벤치마크를 재사용하고, 명시적인 근거가 있는 업종과 ETF만
검토 패킷에 결합한다. 전역 매핑 함수나 기존 후보 파일을 갱신하지 않는다.

중복 근거, 상장 시장·이름 불일치, 보존 KIS 코드 불일치, 기존 assigned/
proposed/curated 업종 불일치, 잘못된 근거 날짜·URL·종류, ETF metadata
불일치는 별도 사유로 보류한다. 공백/000 및 다른 종목의 KIS 코드를 사용한
추론은 없다. 이번 실제 자료의 충돌 0개와 근거 부족 2,062개를 구분한다.

기존 `assess_candidates`, `cap_provenance`, `OfflineStageReplay`와 Stage 엔진을
사용한다. 미래/중복/비정상 OHLCV, 일봉 길이, 완료 주봉, MA30/기울기,
정렬된 26주 RS, 7일 freshness 및 KIS·active ETF metadata 검사를 유지한다.
85개 baseline은 저장 JSON의 membership·count·label 일관성을 확인하고
주봉 입력에서 제외한다. 과거 결과와 다른 입력의 Stage 개수를 합하지 않는다.
stdout만 출력하며 승인 bridge와 네트워크는 호출하지 않는다.

## 최소 후속 자료

확대를 위해서는 추가 후보가 실제 포함된 **저장된 공식 업종 ETF 편입 목록**
(ticker·펀드·기준일·출처), 또는 업종 의미가 명시된 KIS 자료가 필요하다.
현재 135개 제안 중 이런 근거가 연결되는 종목은 이미 가격 재수집 없이
재평가할 수 있다. IDXX는 보존 KIS master/ranking의 상장 시장·주식 유형
행 연결이 필요하다. 이번 작업은 이 자료의 새 외부 수집을 수행하지 않았다.

`main`, 기존 가격·후보 원본, 운영 universe, Stage 엔진, workflow/스케줄,
승인 상태는 그대로다. KIS API 재호출, Actions 수동 실행, 운영 승인·활성화,
병합·배포는 0이다. Draft PR은 일괄 처리 코드와 검증 가능한 병목을 검토하기
위한 것으로, 실제 커버리지 확대가 완료됐다는 주장은 하지 않는다.
