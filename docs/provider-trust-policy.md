# 전체 시장 가격 제공자 신뢰 정책 (2026-11-03)

사용자 결정: 중국을 포함한 모든 국가·업종·종목(US/KR/JP, 국가·업종 ETF,
개별 주식, 원자재 등)에 KIS API 가격 및 KIS 제공 조정주가를 기본적으로 신뢰한다.
KIS 지원 시장은 KIS가 기본 소스다. 외부 거래소 독립 가격 대사, 기업행사 전체
재현, KIS 조정 공식·반올림 역산은 Stage readiness의 필수 선행 조건이 아니다.
KIS 미지원 시장의 대체 제공자도 같은 원칙으로 사용한다.

누락·중복·API 오류·비유한/비정상 가격·OHLC/거래량 구조·거래일·충분한 완료
주봉·최신성 검사는 유지한다. ETF 코드·이름·추종 지수 및 KIS 지원 관측도
유지한다. 명백한 오류 발견 시 해당 입력을 보류하고 필요한 범위만 심층 조사한다.
외부 가격 불일치만으로 특정 종목을 영구 차단하지 않는다. 과거 연구 PR
#197~#200은 진단 자료이며 이 정책의 분석 경로에는 필수 의존성이 없다.

가격 신뢰, 공개 재배포 권한, 운영 활성화는 별개다. 개인 가격/응답 원문은
공개 Git에 추가하지 않는다. CHINA_PRIVATE_SNAPSHOT_DIR는 모든 Git checkout
밖의 개인 폴더여야 한다. 설정은 공개 표출 권한 승인이 아니다.

중국 개인 분석은 기존 classify_stage 추세 임계값을 재사용하고 MA30·4주 MA
기울기·**절대** 26주 수익률을 입력한다. 절대 수익률을 시장 대비 RS라고
표시하지 않는다. 기존 US/KR/JP의 벤치마크 상대강도 계산은 변경하지 않는다.
35개 완료 주봉은 이전 주 기울기까지 계산할 최소 길이다. 이전 완료 주와
정확히 7일 간격일 때만 신규 Stage2 여부를 비교한다. 조정 일간 종가 변동이
50%를 넘으면 이상치 조사 대상으로 보류한다. 독립 조정 검증 완료를 주장하지 않는다.

개인 분석 Stage2는 운영 Stage2 목록에 자동 편입되지 않는다. 병합·배포·데이터
활성화는 사용자 승인 전 금지다. 다음 작업도 본 정책을 우선 적용하고 정상
KIS 가격을 다시 외부 대사/조정 역산 대기 상태로 되돌리지 않는다.
